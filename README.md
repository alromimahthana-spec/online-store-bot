# 👗 بوت متجر ملابس - Online Store Bot
### ثناء | thanaa.codes

بوت متجر إلكتروني يعرض الملابس، ويحسب الفاتورة تلقائياً، ويستلم طلبات التوصيل.

## ✨ وش يسوي؟
- يعرض 6 منتجات: فستان سهرة، عباية، تيشيرت، جينز، حجاب، شنطة
- يخلي الزبونة تختار المقاس والكمية
- يحسب المجموع + رسوم الشحن (20 ريال) تلقائياً
- يستلم اسم الزبونة ورقمها وعنوان التوصيل
- يطبع فاتورة كاملة

## 🚀 كيف تشغليه؟
python online-store-bot.py

## 💰 السعر
3000 ريال سعودي - نسخة كاملة للمتاجر

## 📦 مثال على الفاتورة
فستان سهرة - مقاس M x 1 = 180 ريال
المجموع: 180 ريال
رسوم الشحن: 20 ريال
الاجمالي: 200 ريال
